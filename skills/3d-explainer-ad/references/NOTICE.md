# NOTICE

void — is popularly associated with the "Zack D Films" YouTube style and is a public
creative format, not anyone's protected text. The name appears in this skill's
description only as the trigger phrase users actually say.

The method here was written from our own measured build (2026-08-24: a 12-scene
concept ad, two full iterations, frame-level comparison against a reference ad in
the genre) and from observing publicly available tutorial material about how such
ads are commonly produced. **No third-party prompt text, SOP text, or copy is
reproduced in this skill** — every formula, guard and rule in `SKILL.md`,
`references/formulas.md` and `evals.md` is our own wording, and the API mechanics
are this pack's own.

Ads produced for brands the user does not own are concept ads: the skill requires
presenting them as such (SKILL.md hard rule 10), and publishing decisions belong to
the user.
